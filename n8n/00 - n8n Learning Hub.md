## Ground Rules
- Export each finished workflow as JSON and store it in `Workflows/` so you can re-import it later.
- Never paste real credentials or customer data into a note or a prompt.
- Confirm node names against your instance version. n8n renames nodes between releases (for example, Set became Edit Fields).
