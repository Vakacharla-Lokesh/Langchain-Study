# Lab Reflect-E1 — Essay Critique Loop

## Aim
Build a minimal reflection loop: generate a short essay (150-200 words) on a topic, have a critic pass judge it against 3 specific criteria (clarity, structure, has a concrete example), revise based on that feedback, and stop after either 3 rounds or the critic reports no issues.

## Agent Loop Shape
Cyclic LangGraph: generate → reflect → conditional → {revise (back to generate), end}.

## Pseudocode
```
class State(TypedDict):
    topic: str
    essay: str
    critique: str
    round: int

def generate(state):
    if state.get("critique"):
        prompt = f"Revise this essay based on the critique.\nEssay: {state['essay']}\nCritique: {state['critique']}"
    else:
        prompt = f"Write a 150-200 word essay about: {state['topic']}"
    return {"essay": model.invoke(prompt).content, "round": state.get("round", 0) + 1}

def reflect(state):
    critique = model.invoke(f"""Critique this essay on exactly 3 criteria: clarity, structure, concrete example present.
    For each, say PASS or FAIL with a one-line reason. If all 3 PASS, end your response with 'NO ISSUES'.
    Essay: {state['essay']}""").content
    return {"critique": critique}

def should_continue(state):
    if "NO ISSUES" in state["critique"] or state["round"] >= 3:
        return "end"
    return "revise"

# generate -> reflect -> conditional(should_continue) -> {revise: generate, end: END}
```

## Hints & Suggestions
- Print every round's essay + critique, not just the final result — the interesting part of this lab is *watching* what specifically changes between round 1 and round 2's essay.
- Try starting with a deliberately weak first essay (ask for something vague, no examples) to make sure the critique actually catches the "concrete example" criterion failing — if your critic never fails anything, tighten its prompt.
- Note how many rounds it typically takes to converge across 5 different topics — this number matters for cost/latency planning in Lesson 10's theory.
