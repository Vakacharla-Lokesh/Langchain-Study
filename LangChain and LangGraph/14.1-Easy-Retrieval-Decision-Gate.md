# Lab SelfRAG-E1 — Retrieval Decision Gate

## Aim
Build just the first Self-RAG reflection checkpoint in isolation: a router that decides, per incoming question, whether retrieval is needed at all — skipping straight to direct generation for questions the model can already answer confidently.

## Agent Loop Shape
None — single classification call plus a 2-way branch, simplest possible Self-RAG building block.

## Pseudocode
```
class RetrievalDecision(BaseModel):
    needs_retrieval: bool
    reason: str

decision_maker = model.with_structured_output(RetrievalDecision)

test_questions = [
    "What is 15% of 200?",                                    # no retrieval needed
    "What's the capital of France?",                           # no retrieval needed
    "What does our internal deployment runbook say about rollback steps?",  # needs retrieval
    "Summarize the key points from the Q3 planning doc.",        # needs retrieval
]

for q in test_questions:
    decision = decision_maker.invoke(f"""Does answering this question require retrieving external/internal documents,
    or can it be answered directly from general knowledge?
    Question: {q}""")
    print(q, "->", decision)
```

## Hints & Suggestions
- Include a few genuinely borderline questions (something that *could* be answered generally but would benefit from specific internal context) and see which way the router leans — there's no single "correct" answer for these, but it's worth noting the router's default bias (toward retrieving too often, or too rarely).
- Measure this in practice: for 10 test questions, how many retrieval calls would you save by having this gate versus always retrieving? This savings number is the entire value proposition of this checkpoint.
- This lab pairs directly with Lesson 15's Adaptive RAG — notice the conceptual overlap (this is essentially the simplest 2-way version of Adaptive RAG's 3-way router) and keep that connection in mind going forward.
