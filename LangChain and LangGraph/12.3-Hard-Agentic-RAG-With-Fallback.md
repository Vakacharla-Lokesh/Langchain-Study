# Lab AgenticRAG-H1 — Agentic RAG with Web Search Fallback

## Aim
Combine your internal retriever tool with Tavily (Lesson 07) in one agent, and test whether it correctly chooses internal search for in-scope questions and web search for anything your document set doesn't cover — a hand-built preview of what Lesson 13's Corrective RAG formalizes with explicit grading.

## Agent Loop Shape
`create_react_agent` with 2 tools (retriever + Tavily) — relies entirely on tool descriptions and the model's judgment for routing, no explicit grading step yet (that's the CRAG upgrade in Lesson 13).

## Pseudocode
```
retriever_tool = create_retriever_tool(vectorstore.as_retriever(k=3), name="search_internal_docs",
    description="Search internal company documentation about Project Falcon's architecture and deployment. Does NOT cover general knowledge or current events.")

agent = create_react_agent(model, tools=[retriever_tool, tavily_tool])

test_questions = [
    "What database does Project Falcon use?",          # should use retriever
    "What's the latest version of PostgreSQL?",          # should use Tavily (not in internal docs)
    "How do I deploy an update to Project Falcon?",       # should use retriever
    "Who won [recent event]?",                             # should use Tavily
]

for q in test_questions:
    result = agent.invoke({"messages": [HumanMessage(q)]})
    tools_called = [m.tool_calls[0]["name"] for m in result["messages"] if hasattr(m, "tool_calls") and m.tool_calls]
    print(q, "->", tools_called)
```

## Hints & Suggestions
- Build a small scoring table: for each test question, note which tool you *expected* vs. which tool was *actually* called — compute a rough "routing accuracy" percentage across 8-10 questions.
- If routing accuracy is poor, the fix is almost always sharpening the retriever tool's description to more precisely state its scope (what it does and doesn't cover) — this is the exact lever Lesson 03 flagged as the #1 source of tool-selection bugs.
- Deliberately test a question that's ambiguous between the two sources (something plausible as either internal knowledge or general knowledge) — note what the agent does, and consider whether that's actually the right behavior or a routing gap worth fixing with CRAG's explicit grading (next lesson).
