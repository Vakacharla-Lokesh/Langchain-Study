# Lab Reflexion-H1 — Reflexion Coding Agent

## Aim
Build a Reflexion agent that attempts a small coding problem against a real unit test suite (grounded Evaluator, like Lab Reflect-M1, but now across full separate attempts with an accumulating reflection memory, like Lab Reflexion-M1). This combines the two prior Reflexion labs into the paper's actual headline use case: coding tasks scored by test pass/fail.

## Agent Loop Shape
LangGraph cycle: actor (generate code) → evaluator (run tests) → conditional → {reflect → actor, end}, same shape as Lab Reflexion-M1 but with a grounded, execution-based Evaluator instead of a string-match one.

## Pseudocode
```
class CodingReflexionState(TypedDict):
    problem: str
    test_cases: str
    code: str
    test_result: str
    reflections: list[str]
    attempt: int
    success: bool

def actor_node(state):
    reflection_context = "\n".join(state.get("reflections", []))
    prompt = f"""Problem: {state['problem']}
    {"Past lessons: " + reflection_context if reflection_context else ""}
    Write a Python function solving this. Only output the code."""
    code = extract_code(model.invoke(prompt).content)
    return {"code": code, "attempt": state.get("attempt", 0) + 1}

def evaluator_node(state):
    result = execute_in_sandbox(state["code"], state["test_cases"])
    return {"test_result": result.output, "success": result.all_passed}

def reflect_node(state):
    reflection = model.invoke(f"""This code attempt failed some tests.
    Code:\n{state['code']}
    Test output:\n{state['test_result']}
    In 1-2 sentences: what specifically caused the failure, and what should change next attempt?""").content
    return {"reflections": state.get("reflections", []) + [reflection]}

def should_retry(state):
    if state["success"] or state["attempt"] >= 5:
        return "end"
    return "retry"
```

## Hints & Suggestions
- Pick a coding problem with a genuine edge-case trap (e.g., "merge overlapping intervals" — easy to get the boundary condition wrong on adjacent-but-not-overlapping intervals) so the first attempt plausibly fails on a specific, describable reason.
- Compare this lab's success-rate-by-attempt curve against Lab Reflexion-M1's QA version — coding tasks give you an unambiguous, automated pass/fail signal (no LLM-judged ambiguity), which the paper specifically highlights as ideal for Reflexion. Note whether convergence looks faster/more reliable here than in the QA lab.
- Use a real sandbox (subprocess with timeout, or a controlled `exec` in a restricted namespace with resource limits) — same safety caveat as Lab Reflect-M1.
- Stretch: log total tokens/cost across all attempts to failure vs. success, and compare against just running 5 *independent* attempts with no reflection memory at all (a naive retry baseline) — this ablation is exactly what the Reflexion paper uses to isolate the value of the reflection memory itself, separate from just "trying multiple times."
