# Lab ReWOO-E1 — Basic Planner (Plan Without Executing)

## Aim
Build just the **Planner** step in isolation: given a multi-step question, have the model produce a structured plan of `(step_text, tool_name, tool_input, evidence_id)` tuples — without executing anything yet. Confirms you can get reliable structured planning output before wiring the full pipeline.

## Agent Loop Shape
None — single structured-output call, no execution, no loop.

## Pseudocode
```
class PlanStep(BaseModel):
    step_text: str
    tool_name: str
    tool_input: str          # may reference #E1, #E2 placeholders
    evidence_id: str         # e.g. "#E1"

class Plan(BaseModel):
    steps: list[PlanStep]

planner = model.with_structured_output(Plan)
plan = planner.invoke(f"""Break this question into a step-by-step tool-use plan.
Available tools: search, calculator.
Reference earlier evidence with #E1, #E2, etc. where a step depends on a prior result.
Question: {question}""")

for step in plan.steps:
    print(step)
```

## Hints & Suggestions
- Use a genuinely multi-hop question ("What is the population of the capital of the country where the Eiffel Tower is located, divided by 2?") so the plan actually needs 3+ steps with real `#E` dependencies to be interesting.
- Print the raw plan for 5 different questions and manually check: does step 2's `tool_input` correctly reference `#E1` when it should? This is the exact detail the ReWOO lesson flagged as the trickiest implementation point.
- Don't execute anything yet — that's the next lab. This one is purely about getting a clean, dependency-aware plan out of the model.

- None needed for this lab — pure planning output, no execution.
