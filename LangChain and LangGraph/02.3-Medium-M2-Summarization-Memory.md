# Lab M2 — Summarization Memory

## Aim
Every 5 turns, fire a separate LLM call that compresses the conversation so far into a 3-sentence summary, then continue the conversation using that summary plus the last 2 raw turns instead of full history. Log token counts before/after to prove the savings.

## Agent Loop Shape
Chat loop with a periodic side-call — not an agent loop (no tool-calling), but introduces the "extra LLM call as part of memory management" pattern that recurs in more advanced agents.

## Pseudocode
```
history = []
TURN_COUNT = 0
SUMMARIZE_EVERY = 5
running_summary = ""

def chat_turn(user_input):
    global TURN_COUNT, running_summary, history
    history.append(HumanMessage(user_input))
    TURN_COUNT += 1

    context = build_context(running_summary, history)
    response = model.invoke(context)
    history.append(response)

    if TURN_COUNT % SUMMARIZE_EVERY == 0:
        summary_prompt = f"Summarize this conversation in 3 sentences:\n{format(history)}"
        running_summary = summarizer_model.invoke(summary_prompt).content
        history = history[-2:]   # keep only last 2 raw messages, rest is now in summary

    return response.content

def build_context(summary, history):
    msgs = [SystemMessage("You are a helpful assistant.")]
    if summary:
        msgs.append(SystemMessage(f"Earlier conversation summary: {summary}"))
    msgs += history
    return msgs
```

## Hints & Suggestions
- Use `model.get_num_tokens_from_messages()` (or the tokenizer your provider exposes) to log token count of the context sent on each turn — plot/print it across 15 turns with vs. without summarization to make the savings concrete, not just theoretical.
- The summarization call itself costs tokens and latency — measure that cost too, and report net savings, not just the raw context-size reduction.
- Test recall quality after summarization kicks in: ask about something from turn 2 after turn 10 — does the summary preserve it well enough for the model to answer correctly? This is the real tradeoff of this strategy vs. windowed memory (Lab E4).

## Free APIs / Data to Use
- None needed — script your own multi-turn conversation covering a few distinct topics so you can test recall of specific facts post-summarization.
