# Lab CRAG-E1 — Document Grader

## Aim
Build just the grading step in isolation: given a question and a single retrieved document, have the model classify it as `Correct` / `Ambiguous` / `Incorrect` relative to the question. Test it against deliberately mismatched question/document pairs to confirm the grader actually discriminates.

## Agent Loop Shape
None — single structured-output classification call, no graph yet.

## Pseudocode
```
class DocGrade(BaseModel):
    grade: Literal["correct", "ambiguous", "incorrect"]
    reason: str

grader = model.with_structured_output(DocGrade)

test_pairs = [
    ("What is the return policy?", "Returns are accepted within 30 days with a receipt."),   # correct
    ("What is the return policy?", "Shipping takes 5-7 business days."),                        # incorrect
    ("What is the return policy?", "Our policy covers most situations depending on circumstances."), # ambiguous
]

for question, doc in test_pairs:
    result = grader.invoke(f"Question: {question}\nDocument: {doc}\nGrade this document's relevance.")
    print(result)
```

## Hints & Suggestions
- Deliberately construct a few "sneaky" incorrect pairs — a document that shares keywords with the question but doesn't actually answer it (e.g., question about "return shipping cost", document about "return policy timeframe") — this is the realistic failure mode CRAG exists to catch, not obviously unrelated documents.
- Test grading consistency: run the *same* pair through the grader 5 times — if the grade flips between runs on a clear-cut case, your grading prompt needs tightening (add few-shot examples per Lesson 02's pattern).
- Note where "ambiguous" actually gets used vs. where the grader defaults to correct/incorrect for genuinely middling cases — this 3-way distinction is often the hardest part of the grader to get right.
