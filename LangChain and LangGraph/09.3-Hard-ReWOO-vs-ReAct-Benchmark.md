# Lab ReWOO-H1 — ReWOO vs. ReAct Benchmark

## Aim
Run the same set of 5 multi-hop questions through both your ReWOO pipeline (Lab ReWOO-M1) and your ReAct agent (Lesson 04's Lab M4 / Lesson 06's Lab M6), logging total tokens used, wall-clock latency, and answer correctness for each. Reproduce a small-scale version of the paper's efficiency comparison yourself.

## Agent Loop Shape
Both — this lab runs both architectures side by side, not a new loop shape of its own.

## Pseudocode
```
questions = [
    "...",  # 5 genuinely multi-hop questions, same set for both agents
]

results = []
for q in questions:
    t0 = time.time()
    rewoo_answer, rewoo_tokens = run_with_token_tracking(rewoo_graph, q)
    t1 = time.time()
    react_answer, react_tokens = run_with_token_tracking(react_agent, q)
    t2 = time.time()

    results.append({
        "question": q,
        "rewoo": {"answer": rewoo_answer, "tokens": rewoo_tokens, "latency": t1 - t0},
        "react": {"answer": react_answer, "tokens": react_tokens, "latency": t2 - t1},
    })

print_comparison_table(results)
```

## Hints & Suggestions
- Use LangSmith (Lesson 07) to pull exact token counts per run rather than estimating — both graphs should already be traced if you've set the env vars, making this straightforward to extract from the UI or API.
- Deliberately include one question where a tool call is likely to "fail" (e.g., ask about something your fake search tool doesn't cover) — this is where the ReWOO paper's tool-failure robustness claim should show up: does ReWOO's fixed plan handle the gap more gracefully than ReAct's mid-flight confusion, or does it just produce a confidently wrong Solver answer? Either finding is a legitimate lab result, write down which you observed.
- Don't expect a perfectly clean 5x efficiency gain at this small scale (the paper's number comes from full benchmark averages) — the point is observing the *direction and cause* of the difference (fewer total prompt tokens re-transmitted), not reproducing their exact multiplier.

## Free APIs / Data to Use
- Reuse whichever tools you've already built (fake search + calculator, or real Tavily) — keep them identical between the two agents being compared, or the comparison isn't fair.
