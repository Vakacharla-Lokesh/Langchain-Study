# Lab Reflect-H1 — Two-Model Critic (Adversarial Reflection)

## Aim
Build a reflection loop where the Generator and Critic are given deliberately **opposed framings** (even if using the same underlying model) — the Critic is explicitly instructed to be skeptical and adversarial, actively hunting for flaws rather than politely reviewing. Compare output quality and convergence behavior against a "friendly" critic on the same task.

## Agent Loop Shape
Same cyclic shape as earlier reflection labs, but run **twice** per task with two different critic prompt framings, to compare.

## Pseudocode
```
FRIENDLY_CRITIC_PROMPT = "Review this response and suggest improvements if needed."

ADVERSARIAL_CRITIC_PROMPT = """You are a hostile, skeptical reviewer whose job is to find every flaw.
Assume the response is wrong until proven otherwise. Check specifically for:
- Unsupported factual claims
- Logical gaps or unstated assumptions
- Anything a careful reader would object to
Do not be polite. List every issue found, however minor. If you genuinely find nothing after
this scrutiny, say 'NO ISSUES FOUND AFTER ADVERSARIAL REVIEW'."""

def run_reflection_variant(task, critic_prompt_template, max_rounds=4):
    state = {"task": task, "output": "", "critique": "", "round": 0}
    for _ in range(max_rounds):
        state["output"] = generate(state)
        state["critique"] = model.invoke(critic_prompt_template + "\n" + state["output"]).content
        state["round"] += 1
        if "NO ISSUES" in state["critique"]:
            break
    return state

friendly_result = run_reflection_variant(task, FRIENDLY_CRITIC_PROMPT)
adversarial_result = run_reflection_variant(task, ADVERSARIAL_CRITIC_PROMPT)
```

## Hints & Suggestions
- Pick a task with a subtly wrong "obvious" first answer (a reasoning puzzle, a statistics question with a common intuition trap) — this is where the friendly vs. adversarial critic gap should show up most clearly.
- Track round count to convergence for both variants across 5 tasks — the adversarial critic will very likely take more rounds (it's designed to be harder to satisfy) — the interesting question is whether that extra cost actually buys measurably better final output, or just more churn.
- For a genuinely stronger setup (closer to the "two-model" framing in Lesson 10's theory), use a **different, ideally stronger model** as the adversarial critic instead of just a differently-prompted version of the same model — note in your results whether this changes anything versus the same-model version.
- Watch for the failure mode Lesson 10 warned about: does the friendly critic ever rubber-stamp a flawed output ("looks good!") that the adversarial critic catches? Finding even one such case is a meaningful result for this lab.
