# Lab M6 — Hand-Built vs. Prebuilt ReAct Agent

## Aim
Build the same 2-tool agent (from Lesson 04's Medium lab) two ways: as a hand-wired `StateGraph` (agent node + `ToolNode` + conditional edge), and via `create_react_agent` in ~3 lines. Diff behavior on 5 identical test questions to confirm they match.

## Agent Loop Shape
LangGraph ReAct cycle, built twice — this is the lab where the "graph version" of Lesson 04's theory becomes concrete.

## Pseudocode
```
# --- Version A: hand-built ---
from langgraph.prebuilt import ToolNode

class AgentState(TypedDict):
    messages: Annotated[list, add_messages]

def call_model(state):
    return {"messages": [model_with_tools.invoke(state["messages"])]}

def should_continue(state):
    return "tools" if state["messages"][-1].tool_calls else "end"

builder = StateGraph(AgentState)
builder.add_node("agent", call_model)
builder.add_node("tools", ToolNode([search, calculator]))
builder.add_edge(START, "agent")
builder.add_conditional_edges("agent", should_continue, {"tools": "tools", "end": END})
builder.add_edge("tools", "agent")
hand_built_agent = builder.compile()

# --- Version B: prebuilt ---
from langgraph.prebuilt import create_react_agent
prebuilt_agent = create_react_agent(model, tools=[search, calculator])

# --- Compare ---
test_questions = [...]  # 5 questions from Lesson 04's Medium lab
for q in test_questions:
    a = hand_built_agent.invoke({"messages": [HumanMessage(q)]})
    b = prebuilt_agent.invoke({"messages": [HumanMessage(q)]})
    print(q, "\nA:", a["messages"][-1].content, "\nB:", b["messages"][-1].content, "\n---")
```

## Hints & Suggestions
- If outputs diverge, check the **system prompt** first — `create_react_agent` may inject a default system message you didn't replicate in Version A. Print both agents' final `messages` list from the start, not just the final answer, to spot this.
- Also diff message *ordering* and *count* per question, not just final text — subtle differences in how tool loops unrolled can produce the same final answer via a different path, which is still worth noticing.
- Once confirmed equivalent, keep using `create_react_agent` for simple cases going forward — you've now earned the right to use the shortcut without it being a black box.
