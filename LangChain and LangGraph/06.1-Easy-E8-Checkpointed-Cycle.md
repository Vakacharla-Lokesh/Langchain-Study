# Lab E8 — Checkpointed Cycle

## Aim
Take the Lesson 05 Hard lab's cyclic draft/critique graph (or build a fresh small cyclic graph if you skipped it) and add a `MemorySaver` checkpointer with a `thread_id`. After running, call `graph.get_state_history(config)` and print how many checkpoints were saved.

## Agent Loop Shape
Cyclic graph (draft → critique → conditional loop back or END) + persistence layer — first lab combining loop and checkpointing.

## Pseudocode
```
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
graph = builder.compile(checkpointer=checkpointer)

config = {"configurable": {"thread_id": "lab-e8-run-1"}}
result = graph.invoke({"draft": "", "critique": "", "topic": "renewable energy"}, config=config)

history = list(graph.get_state_history(config))
print(f"Total checkpoints saved: {len(history)}")
for snap in history:
    print(snap.values, "--- next node:", snap.next)
```

## Hints & Suggestions
- The number of checkpoints should roughly correspond to the number of node executions, not just the number of loop iterations — print each checkpoint's `values` to confirm you understand exactly what got saved at each step.
- Run the same graph a second time with a **different** `thread_id`, then confirm `get_state_history` for the first `thread_id` is unaffected — proves threads are properly isolated.
- Try calling `.invoke(None, config=config)` (passing `None` as input) after the graph already finished with that `thread_id` — see what happens when there's no pending interrupt to resume from (useful groundwork for Lab H2 later).
