# Lab M5 — Conditional Routing Graph

## Aim
Build a graph with a genuine conditional edge: a classifier node labels incoming text as "question" or "complaint," and routes to a different response-generating node depending on the label. Confirm both branches independently with one test input of each type.

## Agent Loop Shape
Branching DAG — no cycle, but the first lab in the sequence with real runtime-decided routing (a preview of what an agent's conditional edge does, minus the loop-back).

## Pseudocode
```
class State(TypedDict):
    text: str
    classification: str
    response: str

def classify(state):
    label = model.invoke(f"Classify as exactly 'question' or 'complaint': {state['text']}").content.strip().lower()
    return {"classification": label}

def answer_question(state):
    return {"response": model.invoke(f"Answer helpfully: {state['text']}").content}

def handle_complaint(state):
    return {"response": model.invoke(f"Respond empathetically and offer next steps: {state['text']}").content}

def route(state):
    if state["classification"] == "question":
        return "question_branch"
    return "complaint_branch"

builder = StateGraph(State)
builder.add_node("classify", classify)
builder.add_node("question_branch", answer_question)
builder.add_node("complaint_branch", handle_complaint)
builder.add_edge(START, "classify")
builder.add_conditional_edges("classify", route, {
    "question_branch": "question_branch",
    "complaint_branch": "complaint_branch",
})
builder.add_edge("question_branch", END)
builder.add_edge("complaint_branch", END)

graph = builder.compile()
```

## Hints & Suggestions
- Test with a deliberately ambiguous input ("why does this keep breaking, how do I fix it?") — it's both a question and a complaint. See which way the classifier leans and decide if that's acceptable for your use case, or if you need a 3rd category.
- The mapping dict passed to `add_conditional_edges` (the 3rd argument) must have keys matching exactly what `route()` returns — deliberately return a typo'd string once to see the runtime error this causes, per Lesson 05's Important Points warning.
- Stretch: add a 3rd classification ("spam") routing to a node that just short-circuits to `END` with a canned response, no LLM call — proves branches don't all need to be equally "heavy."

## Free APIs / Data to Use
- None needed — write 10-15 test sentences covering clear questions, clear complaints, and ambiguous cases.
