# Lab CRAG-M1 — CRAG with Web Search Fallback

## Aim
Wire Lab CRAG-E1's grader into a LangGraph: retrieve documents, grade each, and if **none** are graded `correct`, discard them entirely and fall back to Tavily web search instead — implementing CRAG's "Incorrect" branch (skipping the "Ambiguous" combine-both branch for now, that's Lab CRAG-H1).

## Agent Loop Shape
LangGraph with retrieve → grade → conditional → {generate from internal docs, web search then generate} — a 2-way simplified version of CRAG's full 3-way branch.

## Pseudocode
```
class CRAGState(TypedDict):
    question: str
    documents: list[str]
    grades: list[str]
    generation: str

def retrieve(state):
    docs = vectorstore.as_retriever(k=3).invoke(state["question"])
    return {"documents": [d.page_content for d in docs]}

def grade_documents(state):
    grades = [grader.invoke(f"Question: {state['question']}\nDocument: {d}").grade for d in state["documents"]]
    return {"grades": grades}

def decide(state):
    return "generate" if "correct" in state["grades"] else "web_search"

def web_search(state):
    results = tavily_tool.invoke(state["question"])
    return {"documents": [r["content"] for r in results]}

def generate(state):
    context = "\n\n".join(state["documents"])
    answer = model.invoke(f"Answer using only this context:\n{context}\nQuestion: {state['question']}").content
    return {"generation": answer}

builder = StateGraph(CRAGState)
builder.add_node("retrieve", retrieve)
builder.add_node("grade_documents", grade_documents)
builder.add_node("web_search", web_search)
builder.add_node("generate", generate)
builder.add_edge(START, "retrieve")
builder.add_edge("retrieve", "grade_documents")
builder.add_conditional_edges("grade_documents", decide, {"generate": "generate", "web_search": "web_search"})
builder.add_edge("web_search", "generate")
builder.add_edge("generate", END)
```

## Hints & Suggestions
- Test with a question your internal document set genuinely doesn't cover (deliberately out-of-scope) and confirm it correctly routes to `web_search` — trace through `state["grades"]` to see all-`incorrect` triggering the fallback as designed.
- Test with a question that's well-covered internally and confirm it does **not** waste a Tavily call — check your LangSmith trace (Lesson 07) to verify `web_search` node never ran for that case.
- Compare this lab's behavior against Lab AgenticRAG-H1 (Lesson 12's hard lab) on the *same* out-of-scope test questions — CRAG's explicit grading should route correctly more reliably than the "hope the model figures it out from tool descriptions alone" approach, since the fallback here doesn't depend on the model correctly self-assessing "I don't have this."
