# Lab CRAG-H1 — Full Three-Way CRAG Branch

## Aim
Extend Lab CRAG-M1 to the paper's full design: implement all three branches — `Correct` (refine internal docs, generate), `Incorrect` (discard, web search only), and `Ambiguous` (combine refined internal docs + web search) — plus the knowledge refinement ("decompose-then-recompose") step the simplified Lab CRAG-M1 skipped.

## Agent Loop Shape
LangGraph with a genuine 3-way conditional branch after grading, one branch adding a refinement sub-step before generation.

## Pseudocode
```
def decide(state):
    if "correct" in state["grades"] and "incorrect" not in state["grades"] and "ambiguous" not in state["grades"]:
        return "refine_only"
    elif "correct" not in state["grades"] and "ambiguous" not in state["grades"]:
        return "web_only"
    else:
        return "combine"

def refine_knowledge(state):
    # "decompose-then-recompose": strip each correct-graded document to its key relevant snippet
    correct_docs = [d for d, g in zip(state["documents"], state["grades"]) if g == "correct"]
    refined = [model.invoke(f"Extract only the sentence(s) directly relevant to: {state['question']}\nFrom: {d}").content
               for d in correct_docs]
    return {"documents": refined}

def web_search_node(state):
    results = tavily_tool.invoke(state["question"])
    return {"web_documents": [r["content"] for r in results]}

def combine_node(state):
    correct_docs = [d for d, g in zip(state["documents"], state["grades"]) if g == "correct"]
    refined = refine_knowledge({"documents": correct_docs, "question": state["question"]})["documents"]
    web = tavily_tool.invoke(state["question"])
    return {"documents": refined + [r["content"] for r in web]}

# retrieve -> grade_documents -> conditional(decide) -> {
#     "refine_only": refine_knowledge -> generate,
#     "web_only": web_search_node -> generate,
#     "combine": combine_node -> generate,
# }
```

## Hints & Suggestions
- Construct a test question deliberately designed to trigger each of the 3 branches (one where all retrieved docs are clearly correct, one where all are clearly wrong, one where results are genuinely mixed) — verify all 3 paths actually get exercised, not just the two you already built in Lab CRAG-M1.
- For the refinement step, compare generation quality with vs. without it on a document that's correct but noisy (long, with a lot of irrelevant surrounding text) — the paper's claim is that stripping to key snippets improves generation focus; see if you can observe that in your own outputs.
- The "combine" branch effectively doubles your retrieval-side LLM/API calls (refinement + web search) — measure the added latency/cost against Lab CRAG-M1's simpler 2-way version, and decide for yourself whether the full 3-way + refinement design is worth it for your own future projects versus the simplified version.

## Free APIs / Data to Use
- **Tavily** for web search.

## GitHub References
- `langchain-ai/langgraph` — official CRAG tutorial notebook as a baseline; note that most public LangGraph CRAG tutorials (including this one) actually implement the simplified 2-way version like Lab CRAG-M1 — building the full 3-way + refinement version yourself, as this lab does, goes beyond the typical tutorial and closer to the original paper's design.

## Further Reading
