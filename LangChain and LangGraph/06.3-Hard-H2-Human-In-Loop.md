# Lab H2 — Human-in-the-Loop Side-Effect Agent

## Aim
Build a ReAct agent with a fake `send_email(to, subject, body)` tool (just prints "EMAIL SENT" — pretend it's dangerous). Add `interrupt_before=["tools"]` so the graph pauses before any tool executes. Accept manual CLI input (`approve` / `reject` / `edit args`) and resume the graph accordingly.

## Agent Loop Shape
LangGraph ReAct cycle + checkpointer + `interrupt_before` — the full production-shaped pattern from Lesson 06's theory section.

## Pseudocode
```
@tool
def send_email(to: str, subject: str, body: str) -> str:
    """Send an email. This has real side effects - use carefully."""
    print(f"EMAIL SENT to {to} | Subject: {subject}\n{body}")
    return "Email sent successfully."

checkpointer = MemorySaver()
builder = StateGraph(AgentState)
builder.add_node("agent", call_model)
builder.add_node("tools", ToolNode([send_email]))
builder.add_edge(START, "agent")
builder.add_conditional_edges("agent", should_continue, {"tools": "tools", "end": END})
builder.add_edge("tools", "agent")

graph = builder.compile(checkpointer=checkpointer, interrupt_before=["tools"])

config = {"configurable": {"thread_id": "email-session-1"}}
result = graph.invoke({"messages": [HumanMessage("Email jane@example.com asking to reschedule Friday's meeting")]}, config=config)

# Graph paused before executing the tool. Inspect the pending call:
pending_state = graph.get_state(config)
pending_call = pending_state.values["messages"][-1].tool_calls[0]
print("Pending tool call:", pending_call)

decision = input("approve / reject / edit: ")

if decision == "approve":
    graph.invoke(None, config=config)   # resume, executes the tool as-is
elif decision == "reject":
    graph.update_state(config, {"messages": [ToolMessage(content="User rejected this action.", tool_call_id=pending_call["id"])]})
    graph.invoke(None, config=config)
elif decision == "edit":
    new_args = {...}  # collect edited args from input
    # update_state to overwrite the pending AIMessage's tool_calls with new_args, then resume
    graph.invoke(None, config=config)
```

## Hints & Suggestions
- The trickiest part is resuming correctly: `graph.invoke(None, config=config)` continues from the saved interrupt point using state already persisted — **do not** re-pass the original `HumanMessage` input, or you'll effectively restart the conversation.
- For the "reject" path, you're not calling the tool at all — you're manually inserting a `ToolMessage` that tells the model the action was declined, then letting the agent's next turn react to that (it might apologize, ask what to do instead, etc.) — this reuses the "errors as ToolMessage content" pattern from Lesson 03/Lab H4, just for a human decision instead of a tool failure.
- For "edit," you need `graph.update_state()` to modify the pending `AIMessage`'s `tool_calls` args before resuming — read the LangGraph docs' exact syntax for this carefully, it's easy to corrupt message structure here.
- Test the "approve" path first to confirm your basic wiring works before adding the reject/edit complexity.
