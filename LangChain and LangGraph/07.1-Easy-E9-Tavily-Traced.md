# Lab E9 — Real Search, Traced

## Aim
Get a Tavily API key, wire `TavilySearchResults` into a single-tool `create_react_agent`, ask it something time-sensitive your model's training data wouldn't know, and confirm it actually searches rather than guessing. Enable LangSmith tracing and find this exact run in the UI.

## Agent Loop Shape
`create_react_agent` (LangGraph prebuilt) with one real tool — your first non-fake tool integration.

## Pseudocode
```
import os
os.environ["TAVILY_API_KEY"] = "..."
os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_API_KEY"] = "..."
os.environ["LANGCHAIN_PROJECT"] = "lab-e9-tavily"

from langchain_community.tools.tavily_search import TavilySearchResults
tavily_tool = TavilySearchResults(max_results=3)

agent = create_react_agent(model, tools=[tavily_tool])
result = agent.invoke({"messages": [HumanMessage("Who won the most recent [some award/event]?")]})
print(result["messages"][-1].content)
```

## Hints & Suggestions
- Pick a question about something that happened recently relative to your model's knowledge cutoff — the giveaway that search actually ran (vs. the model guessing) is a correct, specific, current answer it couldn't plausibly know otherwise.
- Open the LangSmith UI project you set and find the run — click into the `TavilySearchResults` step specifically and read the raw JSON it returned, not just the final answer, to see what the agent was actually working with.
- If tracing doesn't show up, double check `LANGCHAIN_TRACING_V2` is the string `"true"`, not the Python boolean `True` — a classic env-var gotcha.

## Free APIs / Data to Use
- **Tavily** (docs.tavily.com) — the tool itself, free tier available.
- Optional cross-check: ask the same question with a plain, non-agentic `model.invoke()` call (no tools) side by side, to visibly contrast the ungrounded guess vs. the grounded, searched answer.
