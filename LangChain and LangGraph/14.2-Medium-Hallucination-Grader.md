# Lab SelfRAG-M1 — Hallucination Grader

## Aim
Build the groundedness/hallucination-checking checkpoint: given a generated answer and the documents it was supposedly based on, grade whether the answer is actually fully supported by those documents, or contains unsupported claims. Test it against a deliberately fabricated answer.

## Agent Loop Shape
None yet — single grading call in isolation, to be wired into a full loop in Lab SelfRAG-H1.

## Pseudocode
```
class GroundednessGrade(BaseModel):
    grounded: bool
    unsupported_claims: list[str]   # empty if fully grounded

hallucination_grader = model.with_structured_output(GroundednessGrade)

documents = ["Returns are accepted within 30 days with a receipt. Refunds are issued to the original payment method."]

# A genuinely grounded answer:
grounded_answer = "You can return items within 30 days if you have your receipt."

# A deliberately fabricated answer (adds a claim NOT in the documents):
hallucinated_answer = "You can return items within 30 days if you have your receipt, and you'll also receive a 10% discount on your next purchase."

for answer in [grounded_answer, hallucinated_answer]:
    grade = hallucination_grader.invoke(f"""Documents:\n{documents}
    Generated answer: {answer}
    Is every claim in the answer directly supported by the documents? List any unsupported claims.""")
    print(answer, "->", grade)
```

## Hints & Suggestions
- Make the fabricated claim plausible-sounding but genuinely absent from the source documents (like the discount example above) — an obviously absurd fabrication is too easy for the grader to catch and won't stress-test it properly.
- Try a partially-grounded answer (mixes one true claim with one fabricated one) and confirm the grader's `unsupported_claims` list correctly isolates just the fabricated part, not the whole answer.
- Run the same grounded/hallucinated pair through the grader 5 times each — check for consistency. A grader that sometimes misses the fabrication needs a more specific prompt (e.g., explicitly instruct it to check each sentence of the answer against the documents individually).
