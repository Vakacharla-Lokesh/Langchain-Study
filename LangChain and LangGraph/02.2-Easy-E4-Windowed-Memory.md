# Lab E4 — Manual Windowed Memory

## Aim
Implement a chat loop that only keeps the last 4 messages in context, and deliberately prove the model "forgets" something said 6 turns earlier. Builds the intuition that "memory" is just a message list you manage yourself.

## Agent Loop Shape
Simple chat loop — no tools, no agent decision-making, just repeated `.invoke()` calls with a manually trimmed message list.

## Pseudocode
```
WINDOW = 4
history = [SystemMessage("You are a helpful assistant.")]

def chat_turn(user_input):
    history.append(HumanMessage(user_input))
    windowed = [history[0]] + history[-WINDOW:]   # keep system + last N
    response = model.invoke(windowed)
    history.append(response)
    return response.content

# Turn 1: chat_turn("My favorite color is teal.")
# Turns 2-7: chat_turn(<filler unrelated questions>)
# Turn 8: chat_turn("What's my favorite color?")  -> should fail to recall
```

## Hints & Suggestions
- Use clearly unrelated filler questions for turns 2-7 (weather, math, jokes) so it's obvious the "forgetting" is due to windowing, not the model ignoring the fact for other reasons.
- Print the exact windowed message list sent on the final turn — visually confirming turn 1 isn't in it is more convincing than just observing the wrong answer.
- Stretch: make `WINDOW` a parameter and find the smallest window size where recall breaks, vs. the largest window size that still fits your model's context comfortably for a 50-turn conversation.

## Free APIs / Data to Use
- None needed — this is a local logic exercise.
