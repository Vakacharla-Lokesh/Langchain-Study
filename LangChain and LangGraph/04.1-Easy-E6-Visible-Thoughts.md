# Lab E6 — Visible Thoughts (ReAct Prompting Effect)

## Aim
Take your Lab M3 hand-rolled tool loop and modify the system prompt so the model explicitly outputs a `Thought:` line (as plain text content) before every tool call. Compare tool selection across 5 runs with vs. without the instruction, on an intentionally ambiguous question.

## Agent Loop Shape
Same manual tool loop as Lab M3 — this lab changes the *prompt*, not the loop mechanics.

## Pseudocode
```
SYSTEM_NO_THOUGHT = "You are a helpful assistant with access to tools."

SYSTEM_WITH_THOUGHT = """You are a helpful assistant with access to tools.
Before calling any tool, briefly state your reasoning as:
Thought: <why you're taking this action>
Then make the tool call."""

ambiguous_question = "I need to know how much 15 plus my stock holding is worth"
# ambiguous because it's unclear whether "stock holding" needs a lookup tool or is nonsense

for prompt_variant in [SYSTEM_NO_THOUGHT, SYSTEM_WITH_THOUGHT]:
    for run in range(5):
        messages = [SystemMessage(prompt_variant), HumanMessage(ambiguous_question)]
        response = model_with_tools.invoke(messages)
        log(prompt_variant, response.content, response.tool_calls)
```

## Hints & Suggestions
- Pick your ambiguous question carefully — it needs at least two plausible interpretations so tool selection can genuinely diverge between runs.
- Log every run's Thought text (if present) alongside which tool got called — you're looking for whether visible reasoning correlates with more *consistent* or more *correct* tool choice across the 5 repeats, not just whether text appears.
- This is a small, informal experiment — you don't need statistical rigor, just enough repeated trials to notice a pattern (or notice there isn't one, which is also a valid finding to write down).

## Free APIs / Data to Use
- None needed — reuse Lab M3's tools.
