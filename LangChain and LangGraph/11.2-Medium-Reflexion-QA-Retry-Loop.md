# Lab Reflexion-M1 — Automated QA Retry Loop

## Aim
Automate what Lab Reflexion-E1 did by hand: build a LangGraph where the Actor attempts a multi-hop QA task (reuse Lesson 04's fake search setup), an Evaluator checks the answer against a known ground truth, and — if wrong — a Self-Reflection node generates its own reflection (not hand-written this time) and stores it in state for the next attempt.

## Agent Loop Shape
LangGraph cycle across full attempts: actor → evaluator → conditional → {reflect → actor (new attempt), end}.

## Pseudocode
```
class ReflexionState(TypedDict):
    question: str
    ground_truth: str
    trajectory: Annotated[list, add_messages]   # reset each attempt
    reflections: list[str]                        # persists across attempts
    attempt: int
    success: bool

def actor_node(state):
    reflection_context = "\n".join(state.get("reflections", []))
    system = f"Answer using available tools. Past lessons learned:\n{reflection_context}" if reflection_context else "Answer using available tools."
    # run a small ReAct-style loop here (reuse Lesson 04/06 pattern), producing a final answer
    answer = run_react_subloop(state["question"], system, tools=[search, calculator])
    return {"trajectory": [AIMessage(answer)], "attempt": state.get("attempt", 0) + 1}

def evaluator_node(state):
    final_answer = state["trajectory"][-1].content
    success = state["ground_truth"].lower() in final_answer.lower()
    return {"success": success}

def reflect_node(state):
    reflection = model.invoke(f"""The task was: {state['question']}
    The attempt's answer was: {state['trajectory'][-1].content}
    The correct answer was: {state['ground_truth']}
    In one or two sentences, explain what likely went wrong and what to do differently next time.""").content
    return {"reflections": state.get("reflections", []) + [reflection]}

def should_retry(state):
    if state["success"] or state["attempt"] >= 4:
        return "end"
    return "retry"

# actor -> evaluator -> conditional(should_retry) -> {retry: reflect -> actor, end: END}
```

## Hints & Suggestions
- Use a small fixed set of (question, ground_truth) pairs where the first attempt is likely to fail for a *specific, fixable* reason (e.g., your fake search tool returns a distractor on the first try, requiring a reformulated query) — random unfixable failures won't demonstrate reflection's value.
- Print the accumulating `reflections` list after each attempt — watch whether attempt 3's reflection is meaningfully different/more refined than attempt 1's, or whether the model just repeats similar generic advice (a sign your evaluator/reflection prompts need sharpening).
- Track success rate across attempt number over 5 different questions — the core empirical claim to test is whether success probability actually rises with attempt number given the growing reflection memory, versus staying flat (which would suggest the reflections aren't actually informative).
