# Lab E7 — Linear LangGraph (No Branching)

## Aim
Build a 3-node linear graph: outline generator → paragraph expander → tweet shortener, taking a topic string through all 3 stages. Print `graph.get_graph().print_ascii()` before running, to build the habit of visualizing before executing.

## Agent Loop Shape
DAG, no cycle, no conditional edges — the simplest possible LangGraph graph, deliberately.

## Pseudocode
```
class State(TypedDict):
    topic: str
    outline: str
    paragraph: str
    tweet: str

def make_outline(state):
    outline = model.invoke(f"Make a 3-point outline about: {state['topic']}").content
    return {"outline": outline}

def expand_paragraph(state):
    paragraph = model.invoke(f"Expand this outline into a paragraph:\n{state['outline']}").content
    return {"paragraph": paragraph}

def shorten_tweet(state):
    tweet = model.invoke(f"Compress this into a single tweet:\n{state['paragraph']}").content
    return {"tweet": tweet}

builder = StateGraph(State)
builder.add_node("outline", make_outline)
builder.add_node("expand", expand_paragraph)
builder.add_node("shorten", shorten_tweet)
builder.add_edge(START, "outline")
builder.add_edge("outline", "expand")
builder.add_edge("expand", "shorten")
builder.add_edge("shorten", END)

graph = builder.compile()
print(graph.get_graph().print_ascii())
result = graph.invoke({"topic": "the history of chess"})
```

## Hints & Suggestions
- Run `.stream(input, stream_mode="values")` instead of `.invoke()` once and print the state after each node — get comfortable seeing intermediate state before Lesson 06 relies on this for debugging agent loops.
- Notice that none of these 3 fields use a reducer (`Annotated[...]`) — each node just returns its own new key, no merging conflicts happen here. This is the simple case; Lesson 06 introduces where reducers become necessary.
- Deliberately misspell a node name in one `add_edge` call and observe the error — knowing what a wiring mistake looks like now saves debugging time later.
