# Lab E1 — LCEL Warm-up (Summarizer Chain)

## Aim
Build a `prompt | model | StrOutputParser` chain that takes any pasted text and returns exactly 3 bullet points summarizing it. Confirms you understand Runnable composition and the `|` operator before anything agent-related.

## Agent Loop Shape
None — single `.invoke()` call, no branching, no tools.

## Pseudocode
```
prompt = ChatPromptTemplate([
    ("system", "Summarize the user's text in exactly 3 concise bullet points. No preamble."),
    ("human", "{text}")
])
chain = prompt | model | StrOutputParser()

result = chain.invoke({"text": <pasted_text>})
print(result)
```

## Hints & Suggestions
- Force the "exactly 3" constraint in the system prompt, then actually count the output bullets across 5 different input texts — models drift on exact counts more often than you'd expect.
- Try `chain.stream(...)` instead of `.invoke(...)` and print chunks as they arrive — good first taste of streaming before it matters more in later labs.
- Bonus: swap `StrOutputParser` for `.with_structured_output()` returning `{bullets: list[str]}` and compare reliability of hitting exactly 3 items.

## Free APIs / Data to Use
- No external API needed — use any article text, or pull one via Wikipedia's free REST API (`https://en.wikipedia.org/api/rest_v1/page/summary/{title}`, no key) if you want fresh input text each run.
