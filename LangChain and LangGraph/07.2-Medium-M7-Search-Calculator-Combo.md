# Lab M7 — Search + Calculator Combo, Traced

## Aim
Combine Tavily search with your calculator tool (from Lesson 03) into one ReAct agent, and give it a question requiring both — a real-data lookup followed by arithmetic on the result. Pull up the LangSmith trace and manually verify the Thought/Action/Observation sequence matches the ReAct paper's description.

## Agent Loop Shape
`create_react_agent` with 2 tools, one real (Tavily) one local (calculator) — mixed real/local tool usage.

## Pseudocode
```
agent = create_react_agent(model, tools=[tavily_tool, calculator])

question = "Search for the current population of Japan, then calculate what 2% of that is."
result = agent.invoke(
    {"messages": [HumanMessage(question)]},
    config={"configurable": {"thread_id": "lab-m7"}}
)
print(result["messages"][-1].content)
```

## Hints & Suggestions
- Before running, write down what you *expect* the trace to look like: search call → extract number from result → calculator call → final answer. Then compare the real LangSmith trace against your prediction — mismatches are the interesting part of this lab.
- Watch specifically for whether the model correctly extracts the numeric population figure from Tavily's (often verbose, multi-source) search results before handing it to the calculator — this extraction step is where multi-tool agents most often go subtly wrong.
- Try a version where the search result is ambiguous (multiple different population figures from different sources) and see how the agent handles the discrepancy — does it pick one, average them, or ask for clarification?

## Free APIs / Data to Use
- **Tavily** for search.
- No API needed for the calculator (local tool).

## GitHub References
- `MuhammadAbdullah95/langgraph-cookbook` — `agentic_rag.ipynb` combines search-style tools with downstream processing steps in a similar multi-tool pattern.

## Further Reading
- Yao et al., *ReAct* paper — Section 3 methodology, re-read specifically the description of how Thought steps mediate between raw Observations and the next Action; this lab is a live demonstration of that mechanism.
