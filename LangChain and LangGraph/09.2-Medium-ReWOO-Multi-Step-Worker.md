# Lab ReWOO-M1 — Full Planner → Worker → Solver Graph

## Aim
Wire the complete ReWOO pipeline as a 3-node LangGraph: Planner produces the plan (Lab ReWOO-E1's output), Worker executes each step in order substituting `#E` placeholders with real results, Solver synthesizes the final answer from the full plan + evidence.

## Agent Loop Shape
LangGraph DAG (not a cycle) — Planner → Worker → Solver is linear at the graph level; the "looping" happens *inside* the Worker node as it steps through the plan.

## Pseudocode
```
class ReWOOState(TypedDict):
    question: str
    plan: list[PlanStep]
    evidence: dict[str, str]   # {"#E1": "Paris", "#E2": "2.1 million", ...}
    answer: str

def planner_node(state):
    plan = planner.invoke(state["question"])
    return {"plan": plan.steps, "evidence": {}}

def worker_node(state):
    evidence = dict(state["evidence"])
    for step in state["plan"]:
        resolved_input = step.tool_input
        for eid, val in evidence.items():
            resolved_input = resolved_input.replace(eid, val)
        result = tool_map[step.tool_name].invoke(resolved_input)
        evidence[step.evidence_id] = str(result)
    return {"evidence": evidence}

def solver_node(state):
    context = "\n".join(f"{step.step_text} -> {state['evidence'][step.evidence_id]}" for step in state["plan"])
    answer = model.invoke(f"Given this plan and evidence, answer the question.\n{context}\nQuestion: {state['question']}").content
    return {"answer": answer}

builder = StateGraph(ReWOOState)
builder.add_node("planner", planner_node)
builder.add_node("worker", worker_node)
builder.add_node("solver", solver_node)
builder.add_edge(START, "planner")
builder.add_edge("planner", "worker")
builder.add_edge("worker", "solver")
builder.add_edge("solver", END)
```

## Hints & Suggestions
- The placeholder substitution (`resolved_input.replace(eid, val)`) is naive string replacement — good enough for a lab, but notice how fragile it is (what if `#E1` appears as a substring of `#E10`? order your replacements or use more distinctive placeholder tokens to avoid this).
- Print the full `evidence` dict at the end and manually trace it against the plan — confirm each step's result is what you'd expect before trusting the Solver's final answer.
- Compare this graph's total token usage against Lab M4's ReAct multi-hop agent (Lesson 04) on the *same* multi-hop question — this side-by-side comparison is the actual point of ReWOO's efficiency claim, and sets up Lab ReWOO-H1's formal benchmark.
